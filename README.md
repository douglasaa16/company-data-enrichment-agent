# Company Data Enrichment Agent

Homework assignment: build an agent that takes a list of company names and augments them with location, phone number, and website.

- `companies_input.csv` — starter list (50 outdoor/adventure gear companies)
- `agent.py` — main enrichment agent (search + fetch + extract, with resume/checkpoint support)
- `fix_missing.py`, `fix_missing2.py` — QA follow-up passes for entries missed or containing masked/incorrect data on the first pass
- `starter-companies-augmented.csv` / `.xlsx` — final output spreadsheet
- `agent_log.jsonl` — per-company source log for traceability
- `reflection.pdf` — 1-page reflection on tools, approach, and challenges
